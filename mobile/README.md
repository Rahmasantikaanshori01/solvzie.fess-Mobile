# Solvzie.fess Mobile

A mobile application for Solvzie.fess built with Flutter.

## Tech Stack

- Flutter
- Dart

## Getting Started

Clone the repository:

bash
git clone https://github.com/Rahmasantikaanshori01/solvzie.fess-Mobile.git

Navigate to the project directory:

bash
cd solvzie.fess-Mobile

Install dependencies:

bash
flutter pub get
