# Solvzie.fess Mobile

Solvzie.fess is a mobile application built with Flutter. This repository contains the mobile application source code.

## Tech Stack

- Flutter
- Dart

## Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/Rahmasantikaanshori01/solvzie.fess-Mobile.git
```

### 2. Navigate to Project Directory

```bash
cd solvzie.fess-Mobile
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run Application

Connect an Android device or start an emulator, then run:

```bash
flutter run
```

## Development

To check the project for potential issues:

```bash
flutter analyze
```

To run tests:

```bash
flutter test
```
